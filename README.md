# scripting-widgets

Scripting（iOS App）独立小组件集中仓库。**每个小组件一个同名子目录**，新组件按名字建目录放入。

## 目录索引

| 目录 | 小组件 | 说明 |
|---|---|---|
| [`Launch/`](./Launch) | 启动台 | 桌面启动器：常用 App / 链接 / 自定义脚本一点直达。基于 [Honye/scripting-scripts](https://github.com/Honye/scripting-scripts/tree/main/scripts/Launch) v1.7.1 全面汉化（v1.7.2） |

## 导入方式

Scripting App → 从 GitHub 导入对应子目录（含 `script.json` 的文件夹）即可。
